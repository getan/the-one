---
title: Definition Space
description: The core repository for Multi-Agent resources in The One.
---

A Definition Space manages composable Multi-Agent resources:

1. Prompt and Skill modules.
2. Tool and MCP modules.
3. Custom Agent presets.
4. Multi-Agent Graph blueprints built by connecting different Agents with communication edges.
5. A per-Space [memory](./memory) the Agent curates and that travels with the Space.

You can browse and author all of these as files, or visually on the [Atlas](./atlas) canvas.
