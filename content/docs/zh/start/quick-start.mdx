---
title: 快速入门
description: 从安装 The One 到运行第一个 Multi-Agent Graph 的最短路径。
---

本指南将带你从安装开始，到在 The One 中运行一个你专属的 Multi-Agent。

1. 安装 The One 并登录。前往官网下载安装包。首次启动的“上手”流程会引导你连接一个模型来源——官方模型服务，或你自己的第三方 Provider——并设置全局默认模型（Default Model，之后随时可在桌面顶栏修改）。

2. 准备你自己的仓储 Space。出厂的 Default Space 是只读的，一键把它复制成你自己的可编辑副本；也可以从分享平台下载别人分享的 Space，或导入本地的 `.zerospace` 包。

![切换与管理定义空间](/docs-assets/images/quick-start-spaces.png)

3. 导入你常用的 Prompt、Skill 和 MCP，用你喜欢的方式来调整 Agent 和 Graph——在预设页手动编辑，或到 [Atlas](../the-one-app/definition-space/atlas) 让 director 用自然语言替你编写。

![Agent 编辑器](/docs-assets/images/agent-editor.png)

4. 开始对话。最简单的入口是内置的对话助手：告诉它你要做什么，它会替你拉起合适的 Graph 团队并指挥它们干活。你也可以直接选择一个 Graph 蓝图和项目路径来[运行](../the-one-app/run)，与其中担任入口角色的 Agent 对话。

![一次正在运行的会话](/docs-assets/images/session-running.png)
