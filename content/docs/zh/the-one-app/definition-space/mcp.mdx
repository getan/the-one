title: MCP
description: 导入和管理常用 MCP 工具。
---

在这里定义 MCP server 连接。本地 stdio 型 server 填写 command、args、环境变量与工作目录；远程 server 使用 Streamable HTTP，填写 URL、headers 或 Bearer token。保存时会自动发现该 server 的工具，也可以随时手动“发现工具”重新枚举。哪个 Agent 能使用哪个 server，则在 Agent 编辑页里启用——MCP 页只负责连接本身。

![MCP Servers 页面](/docs-assets/images/mcp-servers.png)

每个 MCP server 都以一条持久会话运行，所以有状态的 server——浏览器自动化、桌面控制——能在多次工具调用之间保持状态，而不是每次冷启动。保存一个 server 时会自动发现它的工具；Agent 也可以在运行时给自己挂上一个 server：以 `mcp:*` 通配绑定的 server 会在 Agent 的下一个 cycle 被拾取，不需要重开对话。为了让 prompt 保持精简，MCP 工具一律先只以名字和一行描述展示，Agent 用 `search_tools` 检索、用 `load_tool` 拉取某个工具的完整 schema（下个 cycle 起生效）；内置工具则始终携带完整 schema。

不只是 Tools：Agent 还可以列举、读取 MCP server 的 Resources，并取用它的 Prompts。没有显式配置工作目录的本地 stdio server，会在应用专属的 mcp-workspace 下获得自己的独立目录，不会把文件乱写进你的项目树。默认 Space 预置了一个 **Computer Use Harness**（桌面控制 + 浏览器自动化：观察屏幕、点击键入、驱动 Playwright 浏览器）server；其余按需自行添加——内置 Agent 都以 `mcp:*` 通配绑定，你添加的任何 server 都会被它们自动拾取。
