---
title: Agent
description: 创建具有独立模型、提示词和工具能力的 Agent 预设。
---

在我们的 Multi-Agent 中，每一个 Agent 的配置都是彼此独立的，包括模型、提示词和工具；正是因此我们才能让每个 Agent 担任截然不同的角色。

首先从创建第一个 Agent 开始：

1. 为你的 Agent 起个好听的名称。名称就是它的唯一标识——之后重命名时，继承它的 Agent 与引用它的 Graph 蓝图都会被自动迁移。

2. 选择要使用的模型。勾选“使用默认模型”让它跟随全局的默认模型（Default Model，在桌面顶栏配置），或为它单独指定模型、Provider 连接、temperature 与推理（Reasoning）配置。

3. 选择要插入的 Prompt / Skill / MCP 模块，以及可选的补充性 Prompt。Skill 与 MCP 各有一个 All / Custom 开关：保持 All 通配时，之后新增的 Skill 和 MCP server 会被这个 Agent 自动包含；Custom 则逐个挑选。

4. 选择要使用的内置 Tool（关系到模型在 Graph 中的编排能力以及与人类用户交互的能力）。每个工具集都可以展开查看它暴露的具体函数，并可附加实例配置或自定义约束。

一个 Agent 预设还可以继承（base）另一个预设：编辑器会逐字段显示“继承中 / 覆盖”，让一族相似的 Agent 共享同一个底座、只维护差异。

![Agent 编辑器](/docs-assets/images/agent-editor.png)

除了手动编写，你也可以在 [Atlas](./atlas) 画布上让 director 用自然语言替你创建和修改 Agent 预设，或者直接让内置的聊天助手把这件事交给专职的编写团队完成。一个 Agent 预设，连同它的 [Graph](./graph) 与其他成员，共同构成一支可复用工作小组的基因——见 [A-Genetic Engineering（Agent 基因工程）](../../multi-agent-architecture/a-genetic-engineering)。
