title: 仓储（Definition Space）
description: Definition Space 是 The One 管理多智能体资源的核心仓储。
---

管理：  
1）可插拔的 Prompt / Skill 模块

2）可插拔的 Tool/MCP 模块

3）自定义组装的 Agent 预设

4）将一个个不同的 Agent 通过任意的边（通讯权限）连接在一起所组成的 Multi-Agent Graph 蓝图

5）一份由 Agent 维护、随 Space 迁移的 [memory](./memory)

以上这些，你既可以作为文件来浏览和编写，也可以在 [Atlas](./atlas) 画布上可视化地编写。
