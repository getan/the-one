---
title: Graph
description: 用节点和边搭建可运行、可观察的 Multi-Agent Graph。
---

在 Graph 上添加的每一个节点都是一个活生生的 LLM Agent，需要绑定之前创建好的 Agent 预设

节点之间相连的边并不是固定的工作流程途径，而是 Agent 之间可被允许的通讯通路，未被边相连的 Agent 之间是无法直接通讯和转交工作的，被相连的 Agent 之间可以通讯并转移状态，但也可以不那么做，一切基于运行过程中 Agent 自身的判断或用户的指示；对边的文本描述都将被 Agent 看到并让他明白箭头对面的 Agent 负责什么工作。

在编辑器里，节点检查器可以为节点绑定 Agent 预设，并追加一段节点专属的 prompt——同一个预设因此能在不同的 Graph 中担任不同的角色。边检查器里填写的描述会在运行时作为移交指令注入给 Agent，所以请把它写完整：何时移交、传递什么、期待对面产出什么。画布还支持校验 Graph、保存，以及蓝图 ID、名称与描述的管理。

![Graph 编辑器](/docs-assets/images/graph-editor.png)

节点上绑定的每个 [Agent 预设](./agent)，加上节点之间的边，共同定义了一支工作小组——这份可复用、可编辑的模版就是它的基因，详见 [A-Genetic Engineering（Agent 基因工程）](../../multi-agent-architecture/a-genetic-engineering)。同样地，你不必只手动拖拽：[Atlas](./atlas) 的 director 或内置聊天助手都能替你连边、增删节点。而当一个 Agent 在运行时把这样一张 Graph 动态地长出来，就是 [Prolifera Engineering（增殖式工程）](../../multi-agent-architecture/prolifera-engineering)。
