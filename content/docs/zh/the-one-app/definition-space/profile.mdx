在这里编写或导入你常用的 Prompt 和 Skill

编写 Prompt 时要注意的是不必在一份 Prompt 中添加所有的内容，因为在 Agent 编辑页面中 Prompt 是可以组合复用的，因此编写一些体量更小但更具有泛用性的 Prompt 会是更好的实践。

![Prompt 编辑器](/docs-assets/images/prompt-editor.png)

导入 Skill 需要输入 repo 地址和要导入的 Skill 名称。如果某个 Skill 网站给出的导入命令是：

```powershell
npx skills add https://github.com/anthropics/skills --skill frontend-design
```

那么你应该填入 source=`https://github.com/anthropics/skills`，skill=`frontend-design`。

![Skill 编辑器](/docs-assets/images/skill-editor.png)
