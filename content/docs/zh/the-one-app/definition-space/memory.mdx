---
title: Memory
description: 每个 Definition Space 都带有一份由 Agent 维护、随它迁移的记忆。
---

一个 Definition Space 带有它自己的 memory：一份基于文件的日志，由 Agent 自己维护，记录它搭建某个 definition 的理由，以及一路上学到的经验。每条记忆都是一个你可以读、可以改的纯文本 Markdown 文件。

Memory 是常驻的。每条记忆每个 cycle 都会以一张折叠卡片的形式投影进 Agent 的上下文，所以 Agent 不用先“查一下”就知道自己记得什么。

![上下文检查器中的 memory 卡片](/docs-assets/images/context-memory.png)

Memory 随 Space 迁移。复制、导入、导出一个 Space，它积累的知识也一起走——于是一个 Space 不再只是一堆静态的 definition，而是一份跨越对话、跨越机器的“组织知识”。

`remember` / `recall` / `update_memory` / `forget` 这组工具可以挂到任意 Agent 上。因为记忆是常驻的，`recall` 只是把折叠的卡片展开；刻意没有“列出记忆”这样的工具——Agent 本来就看得见自己记得什么。[Meditation](../../multi-agent-architecture/more-possibilities/meditation) 的 summarizer 在压缩之前也握着这组工具：真正值得留下的经验会先被写进 memory 再压缩——但它被要求克制，多数冥想不产生新记忆。
