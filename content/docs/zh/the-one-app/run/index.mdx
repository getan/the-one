---
title: 运行
description: 在会话页启动一次 Graph 运行，从上帝视角观察，并随时介入。
---

在会话（Sessions）页新建一个 Graph 实例：选择一个 Graph 蓝图，指定一个可选的项目路径——不指定时，由 Agent 自行决定在哪里工作。会话列表按项目分组，子 Graph 嵌套在拉起它的那次会话之下；与内置助手的对话、Atlas 会话也都在这里，按最近活跃排序。

和其他软件的区别在于透明。你可以清晰地看到 Agent 之间交互的方式和顺序，以及每一个 Agent 的完整上下文：

- **工作链（Work Chain）**展示这次运行的执行链路；**Agent 名册**列出所有被唤醒的 Agent，以及每一个的 LLM 调用次数、工具调用次数与 token 用量；还可以随时打开 Graph 拓扑图查看当前结构。
- 点开任何一个 Agent，检查器有四个标签：**消息**、**上下文**、**工具**、**共享数据**。消息里能看到纯文本推理、以 JSON 树呈现的工具调用参数与结果，以及 **已冥想（Meditated）** 标记——Agent 在哪里压缩了自己的上下文、压缩前后各有多少条消息。
- 你可以随时介入：向任意 Agent 发送补充上下文（支持拖拽图片和文件），回答 Agent 的提问、确认与选择。当 Agent 调用人机交互工具而窗口在后台时，桌面端会弹出原生系统通知，点一下就把应用带回前台。运行可以暂停、恢复、取消。
- 更进一步：你可以编辑你自己发出的任意一条消息并重发——该消息及其后的历史会被丢弃、重新生成；也可以在任意一条消息处把这个 Agent 派生（fork）成同一 Graph 里的新节点——历史保留到选中的那条消息为止，新节点生来断连、未激活。
