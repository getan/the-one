---
title: Dynamic Graph
description: 让 Agent 在运行过程中动态创建、克隆、激活或休眠其他 Agent。
---

在 Graph 中，只要被赋予了对应的 Tool，一个 Agent 就可以创建/克隆/激活/休眠其他 Agent，这让 Graph 可以动态地拓展。

具体来说，一个 Agent 可以从一个已有的 preset 实例化出一个对等 Agent，可以把一个正在运行的 Agent——连同它的配置、上下文和工具——克隆成一个全新身份，也可以把一整个 blueprint 拉起为一个子 Graph 并**充当它自己的人类**，自己回答这个子 Graph 的提问。内置的聊天助手正是用这种方式充当一个路由器：它拉起并指挥各个专精的子 Graph 团队，而不是一个人全干。

这一整套能力——一个 Agent 在运行时把 Graph 长出来——就是我们所说的 [Prolifera Engineering（增殖式工程）](../prolifera-engineering)。有几条不变量值得直说：被克隆或创建出来的 Agent **生来即断连、未激活**，必须先被接入并激活才会做事；Agent 只有在**自己决定**调用工具时才会创建或克隆——长上下文不会触发它，那由 [Meditation](meditation) 另行处理；而一个 Agent 能否这样做，取决于它的 preset 是否被授予了开创工具（`create_subgraph`、`clone_agent_node`、`create_agent_node`、`create_task_board`）。由于这个决定是 Agent 自己的、且没有全局上限，一个被授予工具的 Agent 可以无上限地扇出；这份权柄按设计是集中且可观察的，而非被阻止的。
