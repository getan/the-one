---
title: Dynamic Graph
description: 让 Agent 在运行过程中动态创建、克隆、激活或休眠其他 Agent。
---

在 Graph 中，只要被赋予了对应的 Tool，一个 Agent 就可以创建/克隆/激活/休眠其他 Agent，这让 Graph 可以动态地拓展。

具体来说，一个 Agent 可以从一个已有的 preset 实例化出一个对等 Agent，可以把一个正在运行的 Agent——连同它的配置、上下文和工具——克隆成一个全新身份，也可以把一整个 blueprint 拉起为一个子 Graph 并**充当它自己的人类**，自己回答这个子 Graph 的提问。内置的聊天助手正是用这种方式充当一个路由器：它拉起并指挥各个专精的子 Graph 团队，而不是一个人全干。
