---
title: Multi-Agent 的更多可能
description: Multi-Agent 相比单一 Agent 多出的独特能力边界。
---

Multi-Agent 还有更多独有的特性和可能性，是单一 Agent 所完全不具备的。

- [通讯方式](./communication)：Agent 之间移交任务、共享工作区、并行拉起子 Agent 的几种通路。
- [上下文编辑](./context-editing)：一个 Agent 编辑另一个 Agent 的上下文。
- [Dynamic Graph](./dynamic-graph)：Agent 在运行时创建、克隆、激活、休眠其他 Agent，让 Graph 动态生长。
- [Meditation](./meditation)：Agent 原地压缩自己的历史，自己管理上下文窗口。
- [Self-Evolution](./self-evolution)：一个纯 Agent 的工坊，诊断自己的失败并在正确的层级上修复。
